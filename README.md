# Agente de Atención a Clientes por WhatsApp con IA

Este es un proyecto académico para la universidad.
Consiste en un agente de atención a clientes que responde mensajes
de WhatsApp usando inteligencia artificial.

## ¿Para qué sirve?
Sirve para automatizar respuestas a clientes y consultar información
desde una base de datos.

## Tecnologías usadas
- WhatsApp
- n8n
- Inteligencia Artificial (Claude)
- MCP
- PostgreSQL
- GitLab y Render
